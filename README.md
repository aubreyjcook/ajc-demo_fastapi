# ajc-demo-fastapi

A minimal FastAPI project managed with [`uv`](https://docs.astral.sh/uv/).

## Requirements

- Python 3.10+
- [uv](https://docs.astral.sh/uv/getting-started/installation/) installed and on your PATH
- Git

## First-time setup

```powershell
# Clone / enter the repo
cd ajc-demo_fastapi

# Install dependencies (creates .venv automatically)
uv sync
```

## Running the dev server

uv run fastapi dev
