# ajc-demo-fastapi — Usage & Troubleshooting

## What it is

A minimal **FastAPI "Hello World"** application, managed with [`uv`](https://docs.astral.sh/uv/). It exposes a single endpoint that returns a JSON greeting.

| File | Purpose |
|------|---------|
| `main.py` | The application. Creates a `FastAPI` app and defines `GET /`. |
| `pyproject.toml` | Project metadata, Python requirement, and dependencies. |
| `uv.lock` | Locked dependency versions for reproducible installs. |
| `.gitignore` | Standard Python ignore rules (excludes `.venv`, caches, etc.). |
| `README.md` | Original quick-start instructions. |

## The endpoint

`GET /` returns:

```json
{ "message": "Hello World" }
```

There are no other routes.

---

## Prerequisites

- **Python 3.14+** — note the project actually requires `>=3.14` (see [Troubleshooting](#python-version)).
- **uv** installed and on your `PATH` (`uv --version` to verify). If you don't have the right Python, `uv` can download and manage one for you automatically.

## Setup (first time)

```powershell
cd ajc-demo_fastapi
uv sync
```

`uv sync` creates a `.venv` (if missing) and installs `fastapi[standard]` and all transitive dependencies from `uv.lock`.

> A `.venv` already exists in this checkout, so `uv sync` on a fresh clone will be fast and idempotent.

## Run the dev server

```powershell
uv run fastapi dev
```

What this does:

- `uv run` executes inside the project's virtual environment.
- `fastapi dev` starts **uvicorn** with auto-reload, bound to `http://127.0.0.1:8000` by default.
- Because `pyproject.toml` sets `[tool.fastapi] entrypoint = "main:app"`, you don't need to pass `main:app` on the command line.

You should see output like:

```
INFO     Will watch for changes in these directories: ['...']
INFO     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
```

## Verify it works

In a second terminal:

```powershell
# PowerShell
Invoke-RestMethod http://127.0.0.1:8000/
# or
curl.exe http://127.0.0.1:8000/
```

Expected output:

```
message
-------
Hello World
```

You can also open http://127.0.0.1:8000/ in a browser.

Interactive API docs (auto-generated by FastAPI):

- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

## Stopping the server

Press `Ctrl+C` in the terminal running the server.

## Configuration

- **App object / entrypoint**: `[tool.fastapi] entrypoint = "main:app"` in `pyproject.toml`.
- **Dependency**: `fastapi[standard]>=0.162.0`. The `[standard]` extra bundles `uvicorn`, `fastapi-cli`, `httpx`, `python-multipart`, and other common pieces.
- **Python requirement**: `requires-python = ">=3.14"`.

## Troubleshooting

### `uv` is not recognized
Symptom: `'uv' is not recognized as an internal or external command`.

- Install it: <https://docs.astral.sh/uv/getting-started/installation/>
- Or restart your terminal so the new `PATH` entry takes effect.

### Python version
Symptom: `uv sync` fails with "No solution found" or a Python-version error.

- The project requires **Python 3.14+** (`pyproject.toml`, `requires-python = ">=3.14"`).
- ⚠️ `README.md` says "Python 3.10+" — that is outdated/inaccurate. Trust `pyproject.toml`.
- `uv` normally auto-installs a matching interpreter. To see what it manages: `uv python list`.
- To pin the interpreter for this project: `uv python pin 3.14`.

### Module not found / `fastapi` missing
Symptom: `ModuleNotFoundError: No module named 'fastapi'`.

- You ran `fastapi` (or `python main.py`) outside the virtualenv.
- Fix: always run through `uv`:
  ```powershell
  uv run fastapi dev
  ```
- Or re-sync dependencies:
  ```powershell
  uv sync
  ```

### Port already in use
Symptom: `[Errno 10048] error while attempting to bind on address ('127.0.0.1', 8000)` (Windows) or `Address already in use`.

- Another process is using port 8000. Either stop it or use a different port:
  ```powershell
  uv run fastapi dev --port 8001
  ```
- Find what's on the port (Windows):
  ```powershell
  Get-NetTCPConnection -LocalPort 8000 -State Listen | Select-Object OwningProcess
  ```

### Can't reach it from another machine / container
Symptom: works locally, unreachable from other hosts.

- The dev server binds to `127.0.0.1` by default. Bind to all interfaces:
  ```powershell
  uv run fastapi dev --host 0.0.0.0
  ```
- Check Windows Firewall if the machine still blocks inbound connections.

### Changes aren't reflected
- `fastapi dev` auto-reloads on file changes by default. If you started with `fastapi run` instead, it does **not** auto-reload — restart it.
- Make sure you edited the correct file (`main.py`) and the terminal still shows the reloader running.

### `.venv` is broken / corrupted
Symptom: odd import errors or a partially-installed environment.

- Delete and recreate:
  ```powershell
  Remove-Item -Recurse -Force .venv
  uv sync
  ```

### `404 Not Found` on a path other than `/`
- The app only defines `GET /`. Any other path returns 404. That's expected.

### Slow first `uv sync`
- The first run may download the Python interpreter and packages. Subsequent runs use the cache and are fast.

|--------|---------|
| Install deps | `uv sync` |
